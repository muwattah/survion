# Porodo OneGear — Cinematic Concept Demo

Premium interactive product website demo for **Porodo OneGear** (5000mAh Power Bank + Flashlight + Arc Lighter).

This is a **concept / client demonstration experience**, not an official Porodo storefront.

## Features

- Cinematic loading sequence
- Night camping hero with parallax, stars, fog, embers
- Scroll-driven storytelling (GSAP ScrollTrigger)
- Flashlight beam reveal experience
- Animated 5000mAh power bank section
- Campfire / arc lighter particle experience
- Sticky product feature labels
- Interactive campsite hotspots
- Animated stats & verified specs
- Fully responsive (desktop → mobile)
- `prefers-reduced-motion` support

## Specs used (verified)

- Battery: 5000mAh  
- Type-C I/O: 5V/2.4A (12W Max)  
- Charge time: ~110 min  
- Flashlight: 23H weak / 11H strong  
- Arc lighter + carabiner hook  

## Run locally

Open `index.html` in a modern browser, or serve with any static server:

```bash
npx serve .
# or
python3 -m http.server 8000
```

## Stack

- HTML / CSS / Vanilla JS  
- GSAP 3 + ScrollTrigger (CDN)  
- Canvas particles for embers, dust, fire
