# SURVION ONEGEAR

Cinematic concept experience for **SURVION ONEGEAR**.

- Real physical OneGear product photography
- No countdown, no pre-order
- Scroll-driven storytelling (GSAP)
- Flashlight, power, fire experiences
- Cinematic finale campsite

## Run locally

```bash
npx serve .
```

## Stack

HTML / CSS / Vanilla JS · GSAP 3 + ScrollTrigger · Canvas particles
