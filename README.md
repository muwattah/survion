# SURVION — Cinematic Product Demo

Premium interactive website for **SURVION** — the only outdoor gear product: 5000mAh power bank + flashlight + arc lighter.

## Features

- Cinematic loading sequence
- Night camping hero with parallax, stars, fog, embers
- Scroll-driven storytelling (GSAP ScrollTrigger)
- Flashlight beam reveal
- Animated 5000mAh power section
- Campfire / arc lighter particles
- Sticky product feature labels
- Interactive campsite hotspots
- **Live countdown — launch in exactly 30 days**
- **Pre-order form** (demo, no real payment)
- Fully responsive
- `prefers-reduced-motion` support

## Specs

- Battery: 5000mAh  
- Type-C I/O: 5V/2.4A (12W Max)  
- Charge time: ~110 min  
- Flashlight: 23H weak / 11H strong  
- Arc lighter + carabiner hook  

## Run locally

```bash
npx serve .
# or open index.html
```

## Stack

HTML / CSS / Vanilla JS · GSAP 3 + ScrollTrigger · Canvas particles
